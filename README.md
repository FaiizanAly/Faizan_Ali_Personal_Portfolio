## ✨ Features

- 🍎 Apple-inspired minimalistic design (`#0071E3` accent blue)
- 🌙 Dark / Light mode toggle (persisted in `localStorage`)
- 🔠 Typewriter role animation in hero section
- 📜 Smooth scroll & sticky glassmorphism navbar
- 📱 Fully responsive (mobile, tablet, desktop)
- 🎞️ Scroll-triggered fade-in animations (`IntersectionObserver`)
- 📊 Animated skill progress bars
- 🔽 Project filter tabs (All / Featured / Mini)
- 📬 Contact form with `mailto:` pre-fill
- 💬 Tawk.to live chat widget (bottom-right)
- ⬆️ Scroll-to-top button
- 🔍 SEO meta tags + JSON-LD structured data + Open Graph

## 🚀 GitHub Pages Deployment

1. Create a GitHub repository (e.g. `faiizanaly.github.io`)
2. Upload all files maintaining the folder structure above
3. Go to: **Settings → Pages → Deploy from branch → main / root**
4. Your portfolio will be live at: `https://faiizanaly.github.io/`
